TalentMatch ATS — System Guide

Resume Folder Access, File Processing & Local AI Information Extraction

Architecture & User Guide

Core Flow: When a user connects a local resume folder, TalentMatch operates 100% locally on their computer. It extracts text from all resumes (PDF, Word, Text), runs local AI parsing (via Ollama or built-in engine), compiles complete candidate dossiers, and scores job matches without uploading sensitive files to any cloud.

1. What Happens When Folder Access Is Granted

1 Native OS Folder Picker

User clicks "Connect Folder". The operating system prompts for folder selection with read-only access. Files remain entirely on the local device.

2 Recursive Scan & File Discovery

The scanner looks through all root files and subdirectories. Supported formats (.pdf, .docx, .doc, .txt) are queued. Other formats are safely ignored.

3 In-Memory Text Extraction

• PDF: Reconstructed spatially from top-to-bottom and left-to-right (avoids broken columns).
• Word (.docx): Extracted via Mammoth directly into clean structured text.

4 AI Clinical Extraction (Ollama / Local LLM)

Resume text is processed by a local model (such as llama3.2:3b at localhost:11434) into a structured JSON record.

5 Profile Storage & Job Match Calculation

Profiles are saved into local storage and instantly scored against open requisitions to show fit percentage, missing qualifications, and experience match.

💻 Windows Hardware Specs

  • Recommended Local LLM: llama3.2:3b (Ollama)
  • RAM: 8 GB Minimum (16 GB for faster batch)
  • CPU: Intel Core i5 / AMD Ryzen 5 or higher
  • Speed: 10–25s per resume (CPU) / 2–4s (NVIDIA GPU)
  • Cost & Privacy: 100% Free, zero cloud data transfer

⚠️ Key Extraction Caveats

  • Scanned Image PDFs: Image-only photocopies without text layers cannot be read (requires selectable PDF).
  • Legacy .doc format: Older binary formats may lose formatting; .docx and .pdf are best.
  • Browser CORS: For web mode, run set OLLAMA_ORIGINS=* before starting Ollama, or use the Desktop .exe app.
